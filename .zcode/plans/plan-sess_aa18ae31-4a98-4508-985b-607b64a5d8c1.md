# 窗口设置新增「菜单栏」子页：预览显隐开关 + 标题栏避让

## Context

Pancake（WinUI 3 班级看板）顶栏（68px 标题栏）里的菜单栏 `ProjectCommands`（"项目"/"文件"按钮）目前在查看模式下常显。需求：

1. 新设置「预览下显示菜单栏」，**默认关**：查看/预览模式下隐藏菜单栏，进入编辑模式才显示；开启后查看模式也显示（恢复现状）。
2. 新设置「菜单栏避让距离」滑块，**默认 0（不避让）**：拖动使标题栏整体向下移动一段距离，说明文字"用于避让ClassIsland主界面等窗口"。

设置入口：左侧导航「窗口」改为分组（同「外观」样式），下设「窗口」「菜单栏」两个子页。两项均为本机设置，不参与集控同步（`SettingsSchema.Pages` 本就不含 Window 页，网页端/服务端无需改动；不涉及 RemoteCI 文档/插件）。

## 改动文件

### 1. `src/Pancake/Services/ProjectState.cs` — 设置模型
在 `BoardSettingsState` 中新增两个属性（带与现有风格一致的中文注释）：
```csharp
/// <summary>预览（查看模式）下显示顶部菜单栏；默认关闭，菜单栏只在编辑模式显示。</summary>
public bool ShowMenuBarInPreview { get; set; }
/// <summary>标题栏向下避让的距离（px），用于避让 ClassIsland 主界面等窗口。</summary>
public double MenuBarAvoidDistance { get; set; }
```
JSON 整体序列化，旧配置缺字段自动取默认值，无需迁移。

### 2. `src/Pancake.Shared/SettingsSchema.cs` — 登记本机键（必改，有测试校验）
`DeviceLocalKeys`（约 :180）新增：

```csharp
["ShowMenuBarInPreview"] = "本机窗口布局",
["MenuBarAvoidDistance"] = "本机窗口布局",
```

### 3. `src/Pancake/MainWindow.xaml`

- 导航 `:155`：「窗口」项改为分组（照抄 `:156-167` 外观分组的写法，`IsExpanded="True"` `SelectsOnInvoked="False"`），子项「窗口」`Tag="Window"`（沿用图标）与「菜单栏」`Tag="WindowMenuBar"`（图标用 `Symbol="Document"`，与"文件"按钮一致；如需更贴切可在 `Pancake.Controls` 的 Fluent 图标枚举里挑）。
- `:202` `WindowSettingsPanel` 旁新增容器 `<StackPanel x:Name="MenuBarSettingsPanel" Visibility="Collapsed" />`。

### 4. `src/Pancake/MainWindow.Projects.cs` — 菜单栏显隐逻辑
`UpdateProjectCommands()` `:136` 改为同时考虑编辑模式与新开关（班级页 `CloudControlRoot` 一并纳入判断，行为不变更稳）：
```csharp
bool overlayOpen = SettingsRoot.Visibility == Visibility.Visible || CloudControlRoot.Visibility == Visibility.Visible;
ProjectCommands.Visibility = overlayOpen || (!_isEditing && !_settings.ShowMenuBarInPreview)
    ? Visibility.Collapsed : Visibility.Visible;
```
编辑模式进出（`EnterEditing`/`FinishEditing`/`DiscardEditButton_Click`）都经过 `UpdateRichTextToolbar() → UpdateProjectCommands()`（`MainWindow.xaml.cs:518`），`ShowBoard` 也调用它，无需另加钩子；`ShowSettings`/`ShowCloudControl` 的直接 Collapsed 保留。

### 5. `src/Pancake/MainWindow.Settings.cs` — 设置页构建与偏移应用
- 新增轻量应用方法（放在 `ApplyExtendedSettings` 附近）：
```csharp
/// <summary>标题栏向下避让：给顶栏加 TopMargin，上方留空给 ClassIsland 主界面等窗口。</summary>
private void ApplyMenuBarOffset()
{
    if (TopBar is null) return;
    TopBar.Margin = new Thickness(0, Math.Clamp(_settings.MenuBarAvoidDistance, 0, 200), 0, 0);
}
```
  并在 `ApplyExtendedSettings()`（:1343，加在 `ApplyDisplayLayout()` 附近）调用，覆盖启动与编辑模式切换。
- `InitializeExtendedSettings()` 的 Window 块（:62-89）之后构建菜单栏页（复用 `SettingsStack`/`Toggle`/`Range`/`Note`/`RegisterSettingsPage`，写法照抄 `:62-89`）：
  - `Toggle("预览下显示菜单栏", …, changed: () => { UpdateProjectCommands(); ScheduleSave(); }, read: …)`
  - `Note("默认关闭：菜单栏只在编辑模式下显示，查看模式下保持画面整洁；开启后查看模式也会显示"项目""文件"菜单栏。")`
  - `Range("避让距离", 0, 200, …, changed: () => { ApplyMenuBarOffset(); ScheduleSave(); }, read: …)`，仿 `:40-45` 设 `StepFrequency = 1`（整数 px 步进）；拖动走轻量回调避免整窗刷新
  - `Note("用于避让ClassIsland主界面等窗口。")`（用户指定文案）
  - `RegisterSettingsPage("WindowMenuBar", MenuBarSettingsPanel, menuBar, "菜单栏", "设置菜单栏的显示时机与顶部避让。")`

## 已知边界（不处理，只说明）
- 非全屏（Overlapped）时系统最小化/最大化/关闭按钮仍在窗口顶缘，不会随顶栏下移；应用默认全屏启动（全屏下本就无系统标题栏按钮），影响可接受。
- 考试浮层 `ExamOverlay` 是 `Grid.RowSpan="2"` 整窗覆盖，避让偏移不影响考试画面。
