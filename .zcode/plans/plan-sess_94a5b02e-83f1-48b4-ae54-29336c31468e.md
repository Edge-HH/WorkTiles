# 组件库与组件系统重构实施计划

## Context

当前组件系统功能鸡肋：只有天气/噪音两个硬编码在 `MainWindow.xaml` 里的 Border（L86-96），没有基类、没有注册表、没有添加/删除组件的入口。用户要求参考 ClassIsland（`D:\Files\Codes\Projects\Forks\ClassIsland\temp_repo`，Avalonia 3.0 版）的组件库设计，在控制窗增加"组件库"，支持：文本、分割线、日期、倒计时、轮播容器、滚动容器、分组容器、行容器；支持多行布局（每行可调大小）；自由布局模式下完全不限摆放；**组件系统要大改为插件友好的注册式架构，方便后续插件接入**。

已确认的决策（用户未答复，按推荐执行）：Schema 驱动字段设置面板、点击添加、停靠/自由两种模式共用同一组组件实例（各存一套摆法）、大时钟保持独立停靠区。

## 一、组件框架（新建 `src/Pancake/Components/` 目录）

### 1. 注册表与定义 — `Components/WidgetRegistry.cs`

```csharp
public enum WidgetFieldKind { Text, MultilineText, Number, Bool, Color, Font, Enum, Date }
public sealed record WidgetField(string Key, string Label, WidgetFieldKind Kind, JsonNode? Default,
    double? Min, double? Max, double? Step, string? Unit,
    IReadOnlyList<SettingOption>? Options, string? Hint, string? EnableWhen);

public sealed class WidgetDefinition
{
    public required string Key;            // 稳定标识，如 "Text"、"Countdown"
    public required string Name;           // 显示名："文本"
    public required string Icon;           // FluentIcon 符号名
    public string Description; public string Category = "基础";
    public bool IsContainer;
    public required Func<WidgetBase> CreateView;
    public IReadOnlyList<WidgetField> Fields = [];
}

public static class WidgetRegistry   // Register() 查重抛异常；Find(key)
```
**插件接入点**：未来插件程序集只需调用 `WidgetRegistry.Register(...)`，与内置组件走完全相同的路径。本次不做插件加载器，只做干净的注册架构。

### 2. 基类与宿主服务 — `Components/WidgetBase.cs`

```csharp
public interface WidgetHost        // 解耦组件与 MainWindow，插件可复用
{
    event Action? SecondTick;      // 复用 UpdateClock 的 1 秒时钟
    XiaomiWeatherService Weather { get; }   // 现有服务直接暴露
    NoiseMonitorService Noise { get; }
    bool IsDarkTheme { get; }  bool IsEditing { get; }
}
public abstract class WidgetBase : UserControl
{
    public WidgetRuntime Context { get; internal set; }   // Settings JsonObject + SettingChanged 事件 + Host
    public virtual void OnAttached() / OnDetached();
}
```
组件不写 POCO 设置类，直接从 `Context.Settings`（JsonObject）按字段 Key 读取，配类型化扩展助手（`Settings.Number("Interval", 8)`、`.Text("Content","")`、`.Color(...)` 等）。设置变更由 WidgetRuntime 触发 `SettingChanged(fieldKey)` 通知视图刷新。

### 3. 数据模型 — `Services/WidgetProfile.cs`（放在 Services 目录，供 tests 引用）

```csharp
public sealed class WidgetProfileState {
    public int Version = 1;
    public List<WidgetRowState> Rows = [];            // 停靠模式组件区的行
    public List<WidgetInstanceState> Floating = [];   // 自由布局实例
    public Dictionary<string, RegionPlacement> FreePlacements = new(); // 实例Id → 自由坐标
}
public sealed class WidgetRowState { string Id; double HeightShare = 1; List<WidgetInstanceState> Children; }
public sealed class WidgetInstanceState { string Id; string Key; JsonObject? Settings; double WidthShare = 1; List<WidgetInstanceState>? Children; /* 容器子组件 */ }
```
静态助手：`CreateDefault()`（一行 [天气, 噪音] + 自由 Clock/Weather/Noise）、`MigrateLegacy(BoardSettingsState)`（把旧 `Widgets["Clock"/"Weather"/"Noise"]` 坐标迁入 FreePlacements，`Widgets` 字典此后只存停靠键 Split*/ClockMode*）、`Clone()`（编辑快照用）、确保实例 Settings 补齐字段默认值。

## 二、内置组件（`Components/Widgets/`，代码构建视图，仿 `Controls/SubjectTileControl.cs` 风格）

| 组件 | Key | 要点 |
|---|---|---|
| 天气 | Weather | **迁移现有** WeatherWidget Border（图标+WeatherText），读 Host.Weather |
| 噪音 | Noise | **迁移现有** NoiseWidget Border，读 Host.Noise |
| 文本 | Text | 字段：内容(多行)/字号/颜色(空=主题)/粗体/斜体/对齐 |
| 分割线 | Separator | 方向(横/竖)/粗细/颜色/长度比例/对齐 |
| 日期 | Date | 格式预设枚举(2026年11月4日 星期三/2026-11-04/自定义)+自定义格式串；字号/颜色/粗体；走 SecondTick |
| 倒计时 | Countdown | 目标日期(WidgetFieldKind.Date→"yyyy-MM-dd")/标签文案/显示模式(仅天数/天+时分秒/自动)/过期文案；字号/颜色/粗体。天数计算参考 `MainWindow.Exam.cs` FormatCountdown (L226) |
| 轮播容器 | Carousel | 容器；间隔秒/方向(横/纵)；子组件逐个轮显（淡入淡出） |
| 滚动容器 | Scroller | 容器；速度px每秒/方向(向左/向上)/重复间距/悬停暂停；TranslateTransform + DoubleAnimation 平滑跑马灯 |
| 分组容器 | Group | 容器；排列方向/间距/内边距/背景颜色(默认沿用主题组件卡背景)/圆角 |
| 行 | Row | 容器；子组件横向排列按 WidthShare 分宽；间距/对齐。供自由布局和容器内部使用 |

所有字段带默认值；注册位置：`App.xaml.cs` 启动时调用 `BuiltInWidgets.RegisterAll()`。

## 三、渲染与布局整合

### `Controls/WidgetPresenter.cs`（统一渲染器，仿 ClassIsland ComponentPresenter）
- 属性：`WidgetInstanceState Instance` + `WidgetHost Host`；按 Instance.Id 缓存视图实例
- 查注册表解析 Key → CreateView → 合并默认设置 → 绑定 Context；容器递归用子 WidgetPresenter 渲染 Children
- **未知 Key（插件被卸载等）**：显示"未知组件"占位卡，设置保留不丢

### `MainWindow.Layout.cs` 改造
- **停靠组件区**：`ClockComponentsView`（Viewbox 不变，宽高比 6.5 机制保留）内容改为**行宿主**：外层纵向按 HeightShare 分配行高，行内横向按 WidthShare 分配组件宽。`MainWindow.xaml` 中 Weather/Noise 两个 Border 移除，由行宿主内的 WidgetPresenter 呈现
- **自由布局**：`ApplyFreeWidgets` (L147) 重写为遍历 `Profile.Floating`，每个实例包 Viewbox 放入 `FreeWidgetsCanvas`，坐标读 `FreePlacements`（缺失时给默认位置，替代原硬编码 switch L171-178）
- **编辑手柄**：复用现有 `AddWidgetInteractionLayer` (L411) 与 `WidgetSelectionBorderStyle`/`WidgetResizeThumbStyle`/`InvisibleWidgetMoveThumbStyle`（ThemeResources.xaml L88-116），每个实例的手柄层增加 **⚙ 设置** 和 **✕ 删除** 按钮；行上下沿加行高拖动 Thumb（改 HeightShare）、相邻组件间加宽度拖动 Thumb（改 WidthShare）；行工具条支持 ↑↓ 移动/删除行
- 编辑快照：`_widgetEditSnapshot` 扩展为同时快照 `WidgetLayout.Copy(_settings.Widgets)` + `Profile.Clone()`，放弃编辑时一并还原
